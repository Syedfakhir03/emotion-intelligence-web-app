\# Emotion Intelligence Web App



An NLP web application for analyzing emotions in text.



\## Current Status



This project is currently being rebuilt from an earlier IBM Developer Skills Network exercise into a standalone NLP portfolio application.



\## Current Stack



\- Python

\- Flask

\- JavaScript

\- HTML/CSS

\- IBM Skills Network emotion model



\## Planned Improvements



\- Transformer-based emotion classification

\- REST API

\- Modern interactive frontend

\- Automated testing

\- CI/CD

\- Live deployment



\## Attribution



This project originated from an IBM Developer Skills Network NLP exercise and is being substantially redesigned and extended as a personal portfolio project.
